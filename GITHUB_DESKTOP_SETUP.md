# Publishing with GitHub Desktop

1. Extract the `orbital-debris-eda` folder.
2. Open the folder in VS Code and make sure the notebook opens correctly.
3. Open GitHub Desktop.
4. Choose **File → Add Local Repository** and select the `orbital-debris-eda` folder.
5. If GitHub Desktop says it is not yet a Git repository, choose the option to **create a repository here**.
6. Suggested repository name: `orbital-debris-eda`
7. Make the first commit with a message such as:
   `Initial orbital debris EDA project`
8. Click **Publish repository**.
9. Choose Public only if you are comfortable sharing the notebook and cached outputs.
10. Open the GitHub page and verify that `README.md`, the notebook, and figures render correctly.

Before using this repository in an application, read through every notebook cell and make sure you can explain what it does and why it is included.
